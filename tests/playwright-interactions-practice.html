Interact Inside an Embedded Frame
const frame = page.frameLocator('#practice-frame'); await frame.getByRole('button', { name: 'Click Inside Frame' }).click(); // XPath (must run inside the frame too): //button[normalize-space()='Click Inside Frame']
Clicks inside the iframe above are isolated — they won't trigger this page's status message. In Playwright, use frameLocator() and assert inside the frame itself.
