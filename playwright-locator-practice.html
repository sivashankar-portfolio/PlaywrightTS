Playwright Locator Practice Lab

Every element below is captioned with the exact locator to use. Open dev tools and try them in the Playwright inspector / codegen.

Headings & Links — name, level

Page Title Heading (level 1)

User Registration Form

Navigation Link

Buttons — name, exact, disabled, pressed

Submit Button (basic name match)
getByRole('button', { name: 'Submit Form' })
Exact Name Collision Pair (Save Button vs Save Draft Button)
getByRole('button', { name: 'Save', exact: true }) // matches "Save" only
Disabled Delete Account Button
getByRole('button', { name: 'Delete Account', disabled: true })
Bold Toggle Button (pressed state)
getByRole('button', { name: 'Bold', pressed: true })

getByLabel — associates an input with its <label>

Username Field (label + for/id association)

getByLabel('Username')
Password Field (label wraps the input)
getByLabel('Password')
Email Field (aria-labelledby, no visual <label> tag)
Email Address

getByPlaceholder — matches the placeholder attribute

Email Input
getByPlaceholder('Enter your email')
Product Search Input
getByPlaceholder('Search products...')

getByText — matches visible text content

Welcome Message (simple text)

Welcome to our platform

getByText('Welcome to our platform')
Empty State Message
No results found
getByText('No results found')
Order Total (substring vs exact)
Total: $50.00
getByText('Total', { exact: false }) // substring match
getByText('Total: $50.00', { exact: true }) // full match

getByTestId — matches data-testid attribute

Product Thumbnail
